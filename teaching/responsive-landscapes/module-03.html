Refined Instrument & Interface

instrument · interface
Presentation: Apr 5Assignment 2

Download the full module brief (PDF)

In the second module, each pair will develop an instrument that senses the environment (possibly also interacting with it) and an interface that will be used to visualize and control the instrument.

The Geomorphology Table

The geomorphology table in Campbell Hall 118 will be introduced as a space for developing the instrument and interface. There will also be a series of tutorials to explain how interfaces can be created using plugins in Rhino and Grasshopper.

Deliverables

The deliverables for this module will be a prototype instrument and interface that is part working physical prototype and part speculative drawings, diagrams, and renderings.
