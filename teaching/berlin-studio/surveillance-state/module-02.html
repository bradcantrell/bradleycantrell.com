ALAR 8010 — Phase 02 Brief

Method

Phase 02 seeks to develop a more articulated topic that can be situated within Berlin to further unpack how architecture and landscape architecture may address issues of surveillance, environmental monitoring, and privacy. This exploration will be enabled via the introduction of tools to visualize data as well as to develop mappings and narratives of initial concepts.

The objectives of this phase of work are:

  1. Become more familiar with specific sites within Berlin via cartography and data visualization.
  2. Develop visualizations of data streams that are spatial using design tools such as Grasshopper and Rhino.
  3. Understand the relevance of web mapping and how to use these tools to generate a narrative about the city and the topic of surveillance.
  4. Create conceptual design proposals that propose new environmental relationships with the topic of surveillance.

Working in small teams (2–3) you will develop a body of work that maps, visualizes, and generates the potential of architecture and landscape to interface with the topic of surveillance. This phase of the work is not proposing that there is an existing problem; instead the work should mine the potential of this topic to produce catalysts and resistances to the complexities of the surveillance state.

Cartography

Using the web-mapping tools presented in the first two workshops you will create cartographic representations and narratives that situate surveillance within Berlin. These mappings may be accompanied by diagrams, videos, and/or drawings/models.

Data Visualizations

Using available data sources from Berlin create a compelling visualization that explores the temporal dimensions of sensing and monitoring within the city. The initial explorations of these visualizations may begin as non-spatial but should aim to spatialize the information. The visualizations should also confront data in its historical context (stored, archived) and real-time (instantaneous) potential.

Initial Concepts

Using the visualizations and cartography produce a series of design concepts. These concepts should be represented using tools and techniques that are of interest to each team. The work should vacillate between measured drawings and conceptual diagrams but can take on many forms.

Meta Topics

Similar to the Phase 01 research, it is imperative that the research aims to outline a broad subset of actors in an attempt to highlight how the following meta topics are addressed in the mappings, visualizations, and concepts:

  1. Consent
  2. Uneven application across class / race / gender (control / lack of)
  3. Cultural Perception
  4. Aesthetics

Deliverables

  1. Abstract / Narrative, ~800 words
  2. Web Mappings
  3. Data Visualizations
  4. Concept drawings, diagrams, and media
  5. Webpage(s) on the studio website, including all deliverables, videos, resources, etc.
