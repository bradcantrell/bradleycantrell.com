Final Documentation

image archive · book · slides
Pin-up: Nov 24Due: Dec 12

Download the full Documentation brief (PDF)

The final documentation of your semester’s work will involve revising your final project to be archived in three ways: an image archive, a book layout, and slides for PowerPoint. The revisions will be discussed in each student’s pin-up on Monday, November 24th, and the documentation grade will take into account the project revisions and the accuracy of the final archive, document, and slides.

Image Archive

All of your semester work will be documented as jpeg files at full resolution. If sound or movie files are used in the projects they can be saved in the appropriate format, i.e. Quicktime, WMV, mp3, aiff, etc. This archive will be organized in the following folder and filename structure:

  • lastname_firstname/ — this folder will contain all of your work.
  • Within the main folder, a folder will be created for each project and will separate process and final work: /project01/process and /project01/final.
  • Every file placed in these folders must have a filename that includes the following: lastname_firstname_project#_description — for example, cantrell_bradley_project01_brooklynbridgesketch.jpg.

All work will be saved on DVD (or multiple DVDs), clearly and neatly labeled with the student’s first and last name and course number and contained in a jewel case. No loose or unlabeled DVDs will be accepted.

Document

Each student will use the provided InDesign template to create a document of their semester’s work, starting with the precedent study up to the final site design. The document should represent a cohesive narrative that pulls together the semester. The document should have text that explains your methodology in the framework of the class and your design strategies for the intervention, group strategy, and site design. This document will fully explain your work without a verbal presentation; therefore it should be well laid out, articulate, and comprehensive.

The document size will be 6″ x 9″ portrait layout. All images for the document will be formatted at 300dpi with dimensions for use in the publication.

The document will be printed and trimmed to 6″ x 9″ double sided and held together with a single binder clip in the top left corner. The InDesign document will also be saved on a DVD; the InDesign file should sit in a folder with another internal folder that holds all of the image files that are linked to the document. The file and folder names should use the same conventions as the image archive.

PowerPoint

Each student will use the provided PowerPoint template to create a document of their semester’s work, starting with the precedent study up to the final site design.
