❯ cat briefing.mdthe premise

AI supporting environmentally responsive design by interpreting climate, material, landscape, and building-performance as interconnected systems. This module moves beyond generalized sustainability toward precise environmental consequence.

No generated imagery. Instead, students conduct an ecological assessment of a Knoxville living system — reading it with live environmental data, mapping it, and auditing what the machine actually knows versus what it merely asserts.

Possible outputs: ecological systems mapsscenario studiesmaterial response diagramsshort design proposals

❯ ls lectures/three short lectures
01
The Instrument
Computation — now an LLM — is not an oracle but an instrument the designer directs. Knowledge of a living system is co-produced by human + instrument + landscape. Adaptive epistemology.
02
Reading the Living System
Environmental intelligence — how you read climate, hydrology, ecology, and material as interconnected dynamics, not isolated metrics. The assessment core.
03
The Neo-Wilds & Precise Consequence
The difference between greenwash and a defensible, specific ecological outcome — a system that behaves like neither nature nor city.
❯ cat assessment.mdthe deliverable

The deliverable is an ecological assessment / audit of one Knoxville site, built around a live web map.

Students read a living system with real-time data — streamflow, air quality, weather, reservoir levels, species observations — then map it and argue what it means. The machine's role is explicit: it is a scaffold that must be audited.

❯ cat skill.mdthe instrument, codified

A Claude skill ships with the module — a reusable recipe students hand to the model so it produces the live map and structures the assessment. It encodes: the workflow (site → question → live data → map → assessment), the exact API endpoints with Knoxville examples, a Leaflet template, and the verification ledger that separates live-verified from machine-asserted.
