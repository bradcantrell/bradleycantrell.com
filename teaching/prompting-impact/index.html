❯ cat briefing.mdthe premise

Ecological assessment for site design requires discernment, scientific inquiry, technical aptitude, and creative approaches to produce outputs that can be used in design.

Adaptive design treats the landscape as a dynamic, relational system. Water flows, species arrive and leave, and every part answers to the others. The approaches that let a designer interface with this kind of system are instruments. The gauge, the model, the map, the machine. Each reads the system as it changes and returns something the designer can use. The work is to move with it.

❯ open corridor.mapthe river corridor

21 quads that run 2 km along the river and 4 km into the land, aligned end to end on a single straight axis through downtown Knoxville. Each student is assigned one quad and will develop a live map. This synthetic map references all of the quads. Each student can find their reach in the left-hand roster.

❯ cat assessment.mdthree assignments

An ecological assessment of your reach, assembled across three assignments.

First Look reads the quad with your own eyes, then asks the machine twice and compares what you saw against what it claimed. The second assignment brings live data onto the map, river stage, weather, air quality, species observations. The third asks each student to make a proposition for their reach, a design intervention made with the machine and audited against the data.

❯ cat skill.mdthe instrument, codified

A model skill ships with the module. A reusable recipe students hand to the model so it produces the live map and structures the assessment. It encodes the workflow from reach to question to live data to map to assessment. It carries the exact API endpoints, a Leaflet template, and the verification ledger.
